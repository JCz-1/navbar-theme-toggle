# Vehgoo: Delivery Service Website - Theme toggle

A responsive frontend website concept for a fictional delivery service. Vehgoo showcases modern web development through responsive layouts, interactive navigation, and persistent theme management.

[View Live Link](https://jcz-1.github.io/navbar-theme-toggle/) 

---

## Overview

Vehgoo is a frontend portfolio project designed to demonstrate responsive web development and interactive user interface implementation.

## Features

- **Responsive Design:** Adaptive layouts using CSS Flexbox and Grid.
- **Mobile Navigation:** Interactive sidebar navigation for smaller screens.
- **Theme Management:** System, Light, and Dark theme selection.
- **Persistent Preferences:** Local Storage keeps the chosen theme across page refreshes.
- **Cross-Device Layout:** Responsive interface optimised for different screen sizes.

## Built With

 Technology                                  
 HTML5      >   Page structure                       
 Tailwind CSS >  Styling and responsive layouts       
 JavaScript  >  Interactivity and theme management
